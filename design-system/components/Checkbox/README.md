Multi-select control with label, description and indeterminate state.

**Provide:** `label`, optional `description`, `checked`/`onChange` or `defaultChecked`, `indeterminate`, `disabled`.

- Box: 18px, `radius-xs`, 1.5px `border-interactive`; checked fills `brand-primary` with a white check.
- Use for settings lists and bulk track selection (indeterminate on the header checkbox). Use Switch for instant on/off preferences.
