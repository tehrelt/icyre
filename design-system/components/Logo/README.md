The ICYRE brand mark — a "glint card" symbol (a portrait card outline with a four-point spark) and a stroke-built geometric wordmark.

**Provide:** `variant` (`lockup` default, `symbol`, `wordmark`, `app-icon`), `tone` (`holo` default, `ink`), `height` in px.

- Sidebar: `lockup` at 28px. Collapsed rail, player, favicon: `symbol`. Home-screen and splash: `app-icon`.
- The symbol takes the iridescent stroke (`iridescent-border` stops) only on light grounds ≥ 20px; below 20px or on busy imagery use `tone="ink"`.
- The wordmark is always ink `text-primary`. Never recolor it, never set "ICYRE" in a font as a substitute, never add effects.
- Clear space: one symbol-width on every side of the lockup. Minimum sizes: symbol 16px, lockup 20px tall.
- Files for other surfaces are in the Logos asset group.
