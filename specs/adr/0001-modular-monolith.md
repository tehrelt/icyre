# ADR-0001: начать с модульного монолита

## Статус
Accepted.

## Контекст
Полный набор микросервисов на старте создаёт большой operational overhead.

## Решение
Первая реализация может объединять часть доменов в одном Go application при сохранении строгих модульных границ.

Отдельно с начала выделяются:
- media workers;
- Kafka;
- object storage;
- search/analytics infrastructure.

## Последствия
Плюсы:
- быстрее реализация;
- проще debugging;
- меньше distributed failure modes.

Минусы:
- часть компонентов нельзя масштабировать независимо.

## Эволюция
Нагруженные модули могут быть вынесены в отдельные сервисы без изменения доменных контрактов.
