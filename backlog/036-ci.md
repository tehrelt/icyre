## Итог реализации

- `.github/workflows/ci.yml` (push в `main`, каждый PR, отмена устаревших прогонов):
  - `workspace`: каждый модуль в `go.work` (`make work-check`), `go work sync` без diff, `make mod-check`;
  - `go`: `make fmt-check`, `make vet`, `make test`, `make test-race`;
  - `lint`: golangci-lint v2.14 по всем модулям, кэш анализа;
  - `web`: bun lint, typecheck скриптов, vitest, build;
  - `images`: матрица по всем `services/*/Dockerfile` и `workers/*/Dockerfile` (buildx, без push, кэш `type=gha`).
- Кэш Go-модулей и build cache — `actions/setup-go` по `**/go.sum`.
- `.golangci.yml`: standard (errcheck, govet, ineffassign, staticcheck, unused) + bodyclose, copyloopvar,
  errorlint, misspell, nilerr, unconvert; найденное исправлено (сравнение ошибок через `errors.Is`,
  непроверенные ошибки в тестах, лишние конверсии).
- Integration tests в CI — EPIC-037.
