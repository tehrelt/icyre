# MVP milestone

MVP считается достигнутым, когда пользователь может:

1. зарегистрироваться;
2. войти;
3. открыть каталог;
4. найти исполнителя/альбом/трек;
5. загрузить музыкальный файл через admin/content flow;
6. дождаться transcoding;
7. получить signed URL;
8. воспроизвести аудио;
9. создать плейлист;
10. добавить трек в плейлист;
11. сохранить трек в библиотеку;
12. отправить playback события.

И при этом:

- media не проксируется через основной backend;
- события идут через Kafka;
- сервисы имеют health endpoints;
- есть structured logs;
- есть metrics;
- есть traces;
- есть integration tests;
- локальная система поднимается через Docker Compose.
